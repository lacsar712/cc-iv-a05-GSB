# 光伏组串IV扫描台

扫描员提交组串开路电压、短路电流与填充因子。写入后走 PostgreSQL 通知通道叫醒独立工人，工人不轮询空转。填充因子不低于 0.72 为合格，否则衰减。页面是 Vue 3。

## 停电工作票放行规则

组串入队前先核验**该场区当日停电工作票**是否签完：

1. 现场（扫描员或值班长）在顶栏「停电工作票」专页发出当日场区申请，进**待签区**。
2. 值班长签字后票据进**已签区**，该场区当日才允许写入；未签完提交一律被接口拒绝（写入通道硬拦截，不只拦页面）。
3. 申请、签字与**痕迹**同批落库（同一事务），半截签字整体回滚不算数，痕迹区可全程回查；三区无记录时显示「目前空闲」。
4. 发起人禁止给本人负责的场区代签。
5. 观察员（watcher）被值班长授予**临时签字权限**后可代班签字，但自己仍不能入队提交。

## 技术栈

- 后端：Litestar、Uvicorn、psycopg 同步写入
- 工人：`LISTEN/NOTIFY` 唤醒后认领
- 前端：Vue 3、Vite、nginx 反代 `/api`

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/tickets` | 发起当日场区工作票申请（申请与痕迹同事务） |
| GET | `/api/tickets` | `{pending, signed, traces}` 三区数据 |
| POST | `/api/tickets/{id}/sign` | 值班长或临时授权人签字（禁本人代签，签字与痕迹同事务） |
| POST | `/api/grants` | 值班长授予临时签字权限（8 小时有效） |
| GET | `/api/grants` | 当前有效授权列表 |
| DELETE | `/api/grants/{id}` | 值班长收回授权 |
| POST | `/api/logs` | 提交扫描；该场区当日票未签完返回 403 |
